# UKM Sport Website

Website landing page modern, responsif, dan berperforma tinggi untuk Unit Kegiatan Mahasiswa (UKM) Sport.

## ✨ Fitur

- Desain Modern & Responsif
- Hero Section Premium
- Showcase Cabang Olahraga
- Informasi Kegiatan & Agenda
- Galeri Interaktif
- Animasi Scroll yang Halus
- Performa yang Dioptimalkan
- Ramah SEO
- Antarmuka yang Mudah Diakses (Accessible UI)

## 🛠 Teknologi yang Digunakan

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## 📦 Instalasi

```bash
npm install
npm run dev
```

## 🚀 Menjalankan Build Produksi

```bash
npm run build
```
