# UKM Sport Website

Website landing page modern, responsif, dan berperforma tinggi untuk Unit Kegiatan Mahasiswa (UKM) Sport.

## 1. Fitur

- Desain Modern & Responsif
- Hero Section Premium
- Showcase Cabang Olahraga
- Informasi Kegiatan & Agenda
- Galeri Interaktif
- Animasi Scroll yang Halus
- Performa yang Dioptimalkan
- Ramah SEO
- Antarmuka yang Mudah Diakses (Accessible UI)

## 2. Teknologi yang Digunakan

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## 3. Instalasi

```bash
npm install
npm run dev
```

## 4. Menjalankan Build Produksi

```bash
npm run build
```

## 5. Kontribusi

Kontribusi, saran, maupun masukan sangat terbuka untuk membantu pengembangan proyek ini menjadi lebih baik.
